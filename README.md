# Digital Image Processing

This repository contains college coursework, projects, experiments, and implementations related to digital image processing.

Topics may include image enhancement, filtering, segmentation, feature extraction, transformations, and computer vision techniques.

## Colab notebooks

Upload a notebook exported from Google Colab as an `.ipynb` file anywhere in this repository. GitHub automatically renders committed notebooks in its **Preview** view, including saved outputs.

The `Validate notebooks` GitHub Action runs whenever a notebook is added or changed. It checks that every `.ipynb` file is valid notebook JSON and creates downloadable HTML previews as a workflow artifact.

The **Preview** link above opens the rendered notebook directly from this README. The **Download** link downloads the original notebook for Colab or Jupyter. For a standalone HTML preview, open the completed workflow run and download `notebook-previews` from **Artifacts**. To continue working in Colab, use **File > Open notebook > GitHub** and select the repository notebook.
